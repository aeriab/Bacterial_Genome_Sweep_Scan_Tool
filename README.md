This is a tool developed for the Garud Lab at UCLA. It plots scans of bacterial genomes from the Human Microbiome Project dataset, and tells researchers which base pairs along the genome have been under selective pressures. 

Access the tool here: https://aeriab.github.io/Bacterial_Genome_Sweep_Scan_Tool
